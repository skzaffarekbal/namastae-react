## 🧠 Theory

- **What is Emmet?**  
  - Emmet is a free, open-source toolkit for web developers that allows you to write HTML and CSS faster using shorthand syntax, which expands into full code.

- **Difference between Library and Framework?**  
  - Library → You control the flow (e.g., React, jQuery)  
  - Framework → It controls the flow (Inversion of Control) (e.g., Angular)

- **What is CDN? Why do we use it?**  
  - A CDN (Content Delivery Network) is a network of distributed servers that deliver content faster by serving it from the nearest location to the user.

- **Why is React known as React?**  
  - React is named because it "reacts" to changes in state and updates the UI efficiently in a declarative way.

- **What is `crossorigin` in script tag?**  
  - The `crossorigin` attribute enables CORS (Cross-Origin Resource Sharing) for loading external scripts. It allows better error handling and secure requests across different domains.

- **What is difference between React and ReactDOM?**  
  - React is used to build UI components, while ReactDOM is used to render those components into the browser DOM.

- **What is difference between `react.development.js` and `react.production.js`?**  
  - Development build → Includes warnings, debugging tools, and is larger in size  
  - Production build → Optimized for performance, smaller, and no debug warnings

- **What is async and defer?**  
  Both are used in `<script>` tags to improve page loading performance:

  - `async` → Script downloads in parallel and executes immediately after download (order not guaranteed)  
  - `defer` → Script downloads in parallel but executes only after HTML parsing is complete (order preserved)
