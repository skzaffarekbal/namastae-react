## 🧠 Questions

- **What is `NPM`?**
  - NPM (Node Package Manager) is a tool used to install and manage external code libraries for those projects.
- **What is `Parcel/Webpack`? Why do we need it?**
  - Parcel and Webpack are both static module bundlers used in modern web development. Their primary job is to take your raw, modular code (JavaScript, CSS, HTML, images, and other assets) and merge, compress, and optimize them into a unified, browser-compatible format ready for deployment
- **What is `.parcel-cache`?**
  - The `.parcel-cache` directory is a local storage folder generated by the Parcel web application bundler. 
  - Its primary purpose is to store information about your project’s assets and dependencies to speed up the build process.
- **What is `npx`?**
  - `npx` (Node Package Execute) is a powerful tool bundled with npm that allows you to directly execute JavaScript packages and run command-line tools without installing them first. It automatically locates packages—either locally in your project, or by fetching them from the npm registry temporarily
- **What is difference between `dependencies` vs `devDependencies`?**
  - `dependencies` are essential libraries required for an application to run in production (e.g., React, Express), while `devDependencies` are tools needed only during local development and testing (e.g., Webpack, Jest). devDependencies are not included in the final production bundle, keeping it lightweight.
- **What is Tree Shaking?**
  - Tree shaking is a process of removing the unwanted code that we do not use while developing the application.
  - In computing, tree shaking is a dead code elimination technique that is applied when optimizing code.
- **What is Hot Module Replacement?**
  - It means that bundle will keep a track of all the files which you are updating. There is File Watcher Algorithm (written in C++ or in other low level language). It keeps track of all the files which are changing realtime and it tells the server to reload.

- **What is `.gitignore`? What should we add and not add into it?**
  - A .gitignore file is a plain text document usually located in the root of a Git repository. It tells Git which files or folders to intentionally ignore so they are not tracked, staged, or committed to your project’s history.
- **What is the difference between `package.json` and `package-lock.json`?**
  - In package.json we have information about generic version of installed packages. 
  - Whereas in package.lock.json we have information about the specific or exact version of installed packages.
- **Why should I not modify `package-lock.json`?**
  - You should not manually modify package-lock.json because it is an auto-generated file designed to maintain an exact, reproducible snapshot of your project's dependency tree. Altering it directly corrupts synchronization, leading to unpredictable application behavior and environment discrepancies.
- **What is `node_modules`? Is it a good idea to push that on git?**
  - The node_modules folder is a directory in Node.js projects that acts as a central storage for all external libraries and dependencies. It isn't a good idea to push that on git.
- **What is the `dist` folder?**
  - In software development, the dist folder (short for distribution or distributable) is a directory that contains the final, production-ready version of a project
- **What is `browserslist`?**
  - Browserslist is a tool that specifies which browsers should be supported/compatible in your frontend app.
  - It makes our code compatible for a lot of browsers.
  - In package.json file do: 
  ```bash 
  "browserslist": ["last 2 versions"];
  ```
- **What is `Transitive Dependencies`?**
  - A transitive dependency is a package that is not directly listed in your package.json but is required by one of the packages you did install. They are essentially "dependencies of your dependencies". Tht's why node module is too large.

## 📚 Reading Topics

- Read about different bundlers:
  - Vite
  - Webpack
  - Parcel

  - `Vite` is the fastest modern choice, using native ESM for near-instant dev starts, ideal for SPAs and new projects. `Webpack` remains the dominant, highly configurable industry standard for complex, large-scale enterprise apps, though it is slower and complex. `Parcel` offers "zero-config" simplicity, making it great for quick setups and small projects.

- Read about:
  - `^` (caret)
  - `~` (tilde)

  - In a package.json file, the caret (^) and tilde (~) are version range specifiers that dictate how npm or yarn should handle dependency updates.
  - ~version “Approximately equivalent to version”, will automatically update you to all future patch versions that are backwards-compatible, without incrementing the minor version. ~1.2.3 will use releases from 1.2.3 to < 1.3.0.
  - ^version “Compatible with version”, will automatically update you to all future minor/patch versions that are backwards-compatible, without incrementing the major version. ^1.2.3 will use releases from 1.2.3 to < 2.0.0.
